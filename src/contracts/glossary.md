# Level Design Agent 术语表

> 本项目涉及的核心概念定义。标注 [自定义] 的为本项目特定含义。

---

## 核心架构

| 术语 | 全称 | 来源 | 含义 |
|------|------|------|------|
| **IR** | Intermediate Representation | [自定义] | 中间表示。策划的设计意图被结构化为 6 个维度（SPACE / FLOW / FEEL / MECHANIC / ASSET / SYSTEM）的 JSON 数据。所有模块都从 IR 派生产物，IR 是整个系统的"设计语义协议"。 |
| **Skill** | - | [自定义] | 管线中的独立能力单元，负责从 IR 生成特定类型的产物（如气泡图、资产表）。每个 Skill 通过 contract.yaml 声明输入输出。 |
| **Contract** | 契约 | [自定义] | 每个 Skill 的接口声明文件（contract.yaml），定义需要哪些 IR 字段、产出什么格式、质量检查规则。编排器读契约自动裁剪输入。 |
| **Manifest** | 清单 / 状态中枢 | [自定义] | 管线的状态追踪 JSON 文件，记录每个模块的状态（pending / generated / confirmed / locked / skipped）、版本号、文件哈希、修改历史。核心规则：评分通过 = 版本锁定 = 不可重生成。 |
| **DAG** | Directed Acyclic Graph | 计算机 | 有向无环图，描述任务间的依赖关系和执行顺序。本项目的管线就是一个 DAG：IR 填充 → 模块生成 → 组装 → 评分。 |

## 知识与记忆

| 术语 | 全称 | 来源 | 含义 |
|------|------|------|------|
| **RAG** | Retrieval-Augmented Generation | AI 行业 | 检索增强生成。AI 生成内容前，先从知识库检索最相关的历史资料，再结合检索结果生成。让系统能利用"项目自己的经验"而非仅靠通用知识。 |
| **Fact** | 知识条目 | [自定义] | 知识库中的最小知识单元。记录一条可复用的设计经验，带分类（knowledge / preference / context / goal）和置信度评分。 |
| **Confidence** | 置信度 | [自定义] | 对一条 fact 可信程度的评分（0-1）。用户确认 = 0.9，成功案例推断 = 0.7，修改教训 = 0.6，AI 推测 = 0.4。多次验证时上调，上限 0.95。 |
| **Bible** | 设计圣经 | 游戏行业 | 项目的核心设计知识资产。分两层：Level Bible（单关卡知识档案）和 Project Bible（跨关卡提炼的设计模式/反模式）。 |
| **飞轮** | Flywheel | 商业 | 自我强化的正向循环：更多设计 → 更丰富知识库 → 更精准 RAG → 新设计更快更好 → 更多设计。每圈抬高系统起点。 |

## 编排与管线

| 术语 | 全称 | 来源 | 含义 |
|------|------|------|------|
| **编排器** | Orchestrator | [自定义] | 管线的调度中枢，由三个模块组成：记忆模块（RAG 检索/写入）、路由模块（按契约裁剪 IR）、调度模块（按 DAG 执行 Skill）。 |
| **5 槽位** | 5-Slot Context Assembly | [自定义] | 运行时上下文的组装方式。每个 Skill 执行时，上下文由 5 个固定槽位组成：System Prompt + IR 子集 + 上游产物 + RAG 检索 + 示例，总预算恒定 ~5-7K token。 |
| **人工确认节点** | Human-in-the-Loop Checkpoint | 通用 | 管线中预设的暂停点，展示完整产物让用户决策（确认 / 修改 / 回退）。中断位置是配置决定的，不由 AI 临时判断。 |

## 产物与质量

| 术语 | 全称 | 来源 | 含义 |
|------|------|------|------|
| **模块** | Module | [自定义] | 管线生成的单个产物文件（如 bubble_chart.html），是自包含 HTML，双击即可在浏览器打开。11 个模块组装为完整关卡设计文档。 |
| **组装** | Assembly | [自定义] | 将 11 个独立模块 HTML 合并为一份完整关卡设计文档的过程。组装器只做提取和拼接，不改写任何模块内容。 |
| **4 维度评分** | - | [自定义] | 自动质量评估体系：结构完整性（30%）+ 一致性（30%）+ 规范符合度（20%）+ 信息保真度（20%）。≥0.7 为 PASS。 |
| **版本锁定** | Version Lock | [自定义] | 评分通过后产物进入不可重生成状态。修改必须走增量修改流程（读现有文件 → 改指定部分），不能从零重新生成。 |
