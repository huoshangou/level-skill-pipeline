# 流程图绘制规范 — Flowchart Drawing Standards

> 基于 ISO 5807 标准 + 行业最佳实践，适用于 LevelAgent 的玩法逻辑流程图。

## 1. 标准符号

| 符号 | 形状 | 用途 | SVG 实现 |
|------|------|------|---------|
| **起始/终止** | 圆角矩形（stadium） | 流程的开始和结束 | `rx="20"` 大圆角 |
| **处理/动作** | 矩形 | 玩家操作、系统处理 | `rx="4"` 微圆角 |
| **判断/条件** | 菱形 | 条件分支（必须有 ≥2 个出口） | `<polygon>` 或旋转45°矩形 |
| **事件/触发** | 矩形 + 左侧竖线标记 | 外部事件触发（非玩家主动） | 矩形 + 左侧 4px 色带 |
| **子流程** | 双边框矩形 | 可展开的子流程 | 嵌套 `<rect>` |

## 2. 功能类型着色（玩法流程图专用）

| 功能类型 | 填充色 | 边框色 | 适用场景 |
|----------|--------|--------|---------|
| state_neutral | #F5F5F5 | #999999 | 起始/终止/中性状态 |
| event_trigger | #F3E5F5 | #9C27B0 | 外部事件（遭遇、发现） |
| condition_check | #E8F5E9 | #4CAF50 | 条件判断（菱形） |
| player_action | #FFF8E1 | #FF9800 | 玩家主动操作 |
| system_action | #E3F2FD | #2196F3 | 系统响应、演出、核心状态 |
| failure | #FFF3E0 | #FF9800 | 失败状态 |
| forced_exit | #FFEBEE | #F44336 | 异常/强制中断 |

## 3. 布局规则

### 3.1 流向
- **主流向自上而下**，不可随意跳方向
- 主路径（critical path）占据图的**中轴线**
- 分支向**左右展开**，失败/异常通常在右侧

### 3.2 节点排列
- 节点中心对齐到网格（水平网格 200px，垂直网格 100px）
- 同一层级的节点水平对齐
- 节点统一尺寸：宽 140px，高 44px（菱形对角线 80px）
- 节点间垂直间距：最小 56px（留出边标签空间）

### 3.3 菱形判断节点
- **必须有 ≥2 个出口**，每个出口必须有条件标签
- 主路径出口（满足条件）向下
- 失败/否路径出口向右
- 标签紧邻出口线，不悬浮在远处

## 4. 连线规则

### 4.1 线型
- **只使用直角折线**（horizontal + vertical segments），不使用斜线或曲线
- 每条线最多 2 次折弯（起点→水平段→垂直段→终点，或反之）

### 4.2 线型样式
| 类型 | 样式 | 用途 |
|------|------|------|
| 主路径 | 实线，stroke-width: 2 | 关键路径推进 |
| 条件分支 | 实线，stroke-width: 1.5 | 判断出口 |
| 失败/重试 | 虚线，stroke-dasharray: 6,4 | 失败路径、循环回退 |
| 可选跳过 | 虚线，stroke-dasharray: 4,4 | 可跳过/忽略的路径 |

### 4.3 箭头
- 所有线条末端带箭头，指示方向
- 主路径箭头略大（markerWidth: 8），其他箭头较小（markerWidth: 6）

### 4.4 禁止交叉
- **线条不允许交叉**
- 如果无法避免交叉：
  1. 优先调整节点布局消除交叉
  2. 如仍无法消除，使用**连接器**（圆形 + 编号，如 ①②）跳转

### 4.5 循环回退线
- 回退线走图的**右侧外围**，不穿过主流
- 路径：从失败节点 → 向右水平延伸 → 垂直向上 → 水平折回目标节点
- 回退线使用虚线样式
- 在回退线上标注条件（如"重新尝试"）

```
示意：

    ┌──────────┐
    │  接近尝试  │◄─────────────────────┐
    └────┬─────┘                       │
         │ 满足条件              │ 重新尝试
    ┌────▼─────┐         ┌──────┴─────┐
    │ 可接入状态 │         │  接近失败   ├──→ 向右延伸 → 向上折回
    └──────────┘         └────────────┘
```

## 5. 标签规则

- 条件标签紧贴出口线，位于线段的起始端
- 标签字号 11px，颜色 #666
- 菱形的两个出口标签分别在线的左右或上下
- 长条件文字用缩写，完整版写在旁注或图例中

## 6. 复杂度控制

- 单张图最多 **15 个节点**
- 超过 15 个节点时，拆分为子流程（用子流程符号表示）
- 每个判断节点最多 **3 个出口**
- 循环回退最多 **2 层嵌套**

## 7. SVG 实现约束

- 画布宽度：与模块 max-width 对齐（1100px 减去 padding）
- 使用 `<line>` 和 `<polyline>` 画直角折线，不用 `<path>` 的曲线
- 菱形用 `<polygon points="...">` 绘制
- 节点和边标签用 `<text>` + `text-anchor="middle"`
- 箭头用 `<marker>` 定义
